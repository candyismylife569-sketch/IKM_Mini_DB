Мини-СУБД
Консольная система управления базой данных для хранения записей о пользователях.
Функционал

- Добавление записи - ввод имени, возраста и зарплаты
- Вывод всех записей - табличный вывод с нумерацией
- Удаление по индексу - удаление записи по порядковому номеру
- Поиск по полю - поиск по имени, возрасту или зарплате
- Сортировка - сортировка по любому полю
- Сохранение и загрузка - работа с файлом в формате CSV

 Технические особенности

- Язык C++
- Структура данных `stdvectorUserRecord`
- Формат хранения CSV файл (mini_table.txt)
- Архитектура Модульная
- ОС Windows (требуется windows.h)

 Структура проекта

- `main.cpp` - основная программа и меню
- `solutions.cpp` - реализация функций работы с данными
- `header.h` - заголовочный файл с объявлениями
- `mini_table.txt` - файл данных (создается автоматически)

 Компиляция

 Windows
```
g++ -std=c++11 main.cpp solutions.cpp -o mini_db.exe
```

 Запуск
```
mini_db.exe
```

 Формат данных

Структура записи
```cpp
struct UserRecord {
    stdstring name;   только латинские буквы и пробелы
    int age;            1-150
    double salary;      неотрицательное число
};
```

Формат файла (CSV)
```
Имя,Возраст,Зарплата
John,30,50000.5
Alice,25,45000.0
```

 Обработка ошибок

Программа включает обработку
- Некорректного ввода данных
- Выхода за границы массива
- Ошибок работы с файлами
- Нарушения формата данных

 Ограничения
- Требуется Windows из-за использования windows.h
- Поиск только по точному совпадению
- Нет редактирования существующих записей
- Имена только латинскими буквами

 Использование
1. Запустите программу
2. Следуйте пунктам меню
3. Данные автоматически загружаются при запуске
4. Сохраняйте данные перед выходом
